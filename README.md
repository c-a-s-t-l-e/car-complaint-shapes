# Car Complaint Shapes

This repo serves as a central collection of our explorations into the complaints that people file with NHTSA about their cars.

General structure of this project will be organized according to an OKR-style management philosophy:

Our Objective: 

**We will successfully show how car complaints filed with NHTSA have changed over time.**

As measured by our key results:

**1 Data Pipeline**
**1 Shiny Web Applcation for Data Exploration**
**1 Conclusive Report on the Findings**

How this looks like in practice is:

- data collection
- data cleaning
- data analysis by means of tree maps and chronological frequency line plots
- app creation
- conclusion report writing
